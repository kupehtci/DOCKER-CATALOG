# SonarQube

SonarQube is a platform for continuous code quality analisis to detect bugs, vulnerabilities, code smells and security issues.

For this service, different configurations are provided depending in the final usage: 
* `DevelopmentReady`: SonarQube configured for development or testing environments. 
* `ProductionReady`: SonarQube configured with an external database for production environments. 
* `Hardened`: SonarQube service from a hardened image that is protected against vulnerabilities.
